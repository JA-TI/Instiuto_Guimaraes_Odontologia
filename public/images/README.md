# Pasta de Imagens da iGoodonto

Esta pasta foi organizada para armazenar todas as imagens do site institucional da **iGoodonto**.

## 📁 Estrutura de Pastas:

```
public/
└── images/
    ├── logo/            # Logotipo oficial em alta resolução (SVG, PNG transparente)
    │   ├── logo-light.png
    │   ├── logo-dark.png
    │   └── favicon.svg
    ├── hero/            # Imagens de capa/banner principal (1920x1080px ou proporção 4:5 para o card de destaque)
    │   └── hero-banner.jpg
    ├── doctors/         # Fotos em formato retrato dos dentistas especialistas
    │   ├── dra-ana-lucia.jpg      (Dra. Ana Lúcia Guimarães - CRO-MG 15381)
    │   └── dr-fernando-cesar.jpg   (Dr. Fernando César Guimarães - CRO-MG 16129)
    ├── clinic/          # Fotos dos ambientes, consultórios, recepção e equipamentos
    │   ├── consultorio-01.jpg
    │   ├── consultorio-02.jpg
    │   ├── recepcao.jpg
    │   ├── biosseguranca.jpg
    │   └── scanner-3d.jpg
    ├── treatments/      # Imagens e banners específicos de cada especialidade
    │   ├── invisalign.jpg
    │   ├── implantes.jpg
    │   ├── clareamento.jpg
    │   ├── ortodontia.jpg
    │   ├── facetas.jpg
    │   └── periodontia.jpg
    └── testimonials/    # Fotos dos pacientes para prova social
        ├── paciente-01.jpg
        ├── paciente-02.jpg
        └── paciente-03.jpg
```

---
💡 **Dica de Performance:** Recomenda-se utilizar formatos modernos como **WebP** ou **AVIF** para tempo de carregamento ultrarrápido.
